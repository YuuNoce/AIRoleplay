# AIRoleplay

[English version](README.md)

FFXIVのゲーム内チャット用に、AIでロールプレイの返信文を作るDalamudプラグインです。

直近のゲームチャットの内容や、あなたが設定したキャラクター設定を踏まえて、AIが返信文を作成します。対応しているAIは OpenAI、Claude、Gemini、DeepSeek、Z.ai です。

## できること

* AIと喋りながらゲームができる「プライベートモード」
* ゲーム内の他プレイヤーへ向けた発言を作る「パブリックモード」
* 直近のゲームチャットを読み込んで、会話の流れを踏まえた返信を作る
* Say（発言）／Party（パーティ）／Free Company／Tell（個人宛）への下書き作成と、確認してからの投稿
* キャラクターごとのロールプレイ設定（人物像・口調）
* AIモデルが失敗した時のための、最大3つの予備モデル設定
* 会話ログの保存（トラブル時の確認用）

## インストール

Dalamud設定の「Experimental」から「Custom Plugin Repositories」に次のURLを追加してください。

```text
https://raw.githubusercontent.com/YuuNoce/AIRoleplay/master/repo.json
```

保存後、プラグインインストーラーで「AIRoleplay」を検索してインストールします。

## まず知っておくこと：「プライベートモード」と「パブリックモード」

このプラグインには2つのモードがあります。

* **プライベートモード**：AIキャラクターと喋りながらゲームができるモード。話しかける方法は3つあります。

  1. AIRoleplayの画面に直接打つ
  2. ゲームのSay欄に打つ
  3. `/airp メッセージ` コマンドを使う

  このうち②だけは、あなた自身の発言がゲーム内のSayとして他プレイヤーにも見えます（AIRoleplayはその内容を会話の文脈として読み取るだけです）。①と③はゲーム内チャットには何も表示されません。

  **AIの返答は、どの方法で話しかけても他プレイヤーには一切見えません。** AIRoleplayの画面内に表示されるほか、設定次第でゲームのチャットログにも表示させることができますが、それはあなた自身のクライアント上でだけ見える表示であり、投稿ではありません。

* **パブリックモード**：ゲーム内の他プレイヤーへ向けた発言を、AIに考えてもらうモード。ここで作った文章は、Say・Party・FC・Tellとして実際にゲームへ投稿できます。**ダイレクト投稿では、生成文を確認する手順を挟まず、自動的にゲームへ投稿します。**

起動時・ログアウト時・キャラクター変更時は、必ず「プライベートモード」に戻ります。うっかりパブリックのまま人前で変な発言をする、という事故を防ぐための仕様です。

## コマンド

メイン画面を開くには `/airp` と打ちます。画面を開かずに直接指示したい場合は、以下が使えます。

```text
/airp                          → メイン画面を開く
/airp hello                    → 今のモードのまま、AIにメッセージを送る
/airp r [名前] [指示]           → 「返信アシスト」に切り替えて、指定した相手への返信を作る
/airp r <t> [指示]              → 今ターゲットしている相手への返信を作る
/airp target current|party|none|"名前@ワールド"  → 返信アシストの相手を設定する
/airp channel say|party|fc|tell → 投稿先のチャンネルを設定する
/airp status                   → 現在の設定状況を確認する
/airp help                     → コマンド一覧を表示する
```

## 初回設定：LLMのAPIキーを登録する

このプラグインはLLMのAPIキーを保存しません。呼び出す時だけ読み込みます。**AIRoleplayおよび配布者はAPIキーを提供しません。** あなた自身が取得・所持しているLLMのAPIキーを、Windowsに登録してください。

1. Windowsの検索で「資格情報マネージャー」と入力して開く
2. 「Windows資格情報」を選ぶ
3. 「汎用資格情報の追加」をクリック
4. 使いたいAIサービスに応じて、下記の表の通りに入力する

| 使いたいAI | インターネットまたはネットワークのアドレス | ユーザー名 |
| --- | --- | --- |
| OpenAI | `AIRoleplay/OpenAI` | `AIRoleplay` |
| Claude | `AIRoleplay/Claude` | `AIRoleplay` |
| Gemini | `AIRoleplay/Gemini` | `AIRoleplay` |
| DeepSeek | `AIRoleplay/DeepSeek` | `AIRoleplay` |
| Z.ai | `AIRoleplay/Zai` | `AIRoleplay` |

「パスワード」欄には、あなたが所持しているLLMのAPIキーを実際に入力してください。

登録後は、プラグインの設定画面を開き、「LLMモデル設定」タブで「キー状態を再読み込み」を押してください。

## 「返信相手」と「投稿先」の違い（重要）

この2つは名前が似ていますが、まったく別のものです。混同するとトラブルの元になります。

* **返信相手** = AIに「誰に向けた文章を書かせるか」を伝えるための指定
* **投稿先** = 実際にその文章がどのチャンネルに送られるか

つまり――

> 「返信相手」を〇〇さんに設定していても、「投稿先」がSayのままなら、その発言は〇〇さん個人ではなく、周りにいる全員に見えます。

**個人的にこっそり送りたい場合**は、返信相手を指定した上で、**投稿先も明示的にTellに変更**してください。

**返信相手のログが見つからない場合**（「この相手の発言は取得ログにありません」と表示される場合）でも、手動で発言を作ることは可能です。AIには「この相手に向けて」という指示だけが伝わります。

## Tell（個人宛メッセージ）を送る場合

Tellは、送り先を「1人」に確定できる場合だけ使えます。「会話全体」や「パーティ全体」を選んでいる状態では使えません。

送り先の指定方法は3つあります。

| 指定方法 | 説明 |
| --- | --- |
| 直近の発言者から選ぶ | ログに残っているプレイヤーの情報を使う |
| 現在のターゲットに追従 | 今ターゲットしているプレイヤーを送り先にする（NPCや未選択時は不可） |
| 手入力する | `名前@ワールド` の形式で正確に入力する必要がある（ワールド省略は不可） |

送り先が確定できない場合や、入力形式が間違っている場合は、エラーで処理が止まります。「送れないから代わりにSayで送る」といった代替処理は行いません。

他ワールドの人物にTellを送る際は、フレンド登録やパーティ募集など、FFXIV側の制限がかかる場合があります。詳しくは[FFXIV公式のテキストコマンド一覧](https://jp.finalfantasyxiv.com/lodestone/playguide/db/text_command/)を確認してください。

なお、このプラグインが「送信済み」と表示するのは「ゲームに送信操作を行った」という意味であり、「相手に確実に届いた」ことまでは保証しません。

## パーティ全体へ返信する場合

「パーティ全体」は特定の1人ではなく、パーティチャット全体の流れに対して返信を作るモードです。

* パーティの発言を自動で読み込みの対象にします
* 投稿先は自動的にPartyに固定されます

## 返信アシストの使い方（ゲーム画面との連動）

返信アシストモードでは、プラグインの編集画面に書いた文章が、そのままゲームのチャット入力欄に反映されます。

* 改行は自動的に空白に変換されます
* 実際に送信されるのは、あなたがゲーム側でEnterを押した時だけです
* ゲームの入力欄を直接編集・削除すると、連動は解除されます
* モードや投稿先、相手を変更すると、生成中の文章は一旦キャンセルされます

なお、`<` や `>` を含む文章は、ゲーム側の表示バグを避けるため、入力・送信されません。

パブリックモードで使うキャラクター設定（人物像・口調）は、`AIRoleplay/characters/プレイヤー名@ホームワールド/profile.txt` に保存されます。設定画面からテキストを読み込んで保存すると、このファイルが更新されます。

## 会話を長く記憶させる機能（会話要約）

AIとの会話が続くと、話した内容をAIが忘れます。これを防ぐための機能が「AIが生成する会話要約を使用する」です。

初期設定ではOFFになっています。ONにすると、AIは返信を作るたびに「今回の発言」と「更新された会話の要約」を同時に生成し、画面には発言だけが表示されます。要約は裏側で保持され続けます。

要約は、ログアウト・キャラクター変更・プラグインの再読み込み・設定画面からの「内部要約をリセット」で消去されます。**プライベートとパブリックの要約は別々に管理され**、パブリックの場合は「投稿先」と「返信相手」の組み合わせごと（Tellの場合は`名前@ワールド`ごと）に分けて記憶されます。

## ログの保存

ログ保存の初期設定はOFFです。会話画面や設定画面から、保存するかどうか・保存先フォルダを選べます。保存された利用者向けログは `プレイヤー名@ホームワールド/` フォルダの下に、`private.log`（**プライベートモード**用）・`public.log`（パブリックモード用）として残ります。完全なプロンプトやAPI診断情報は通常保存されません。
